


 
==============================================================================
PL_D365_DISPATCHREQUESTS
==============================================================================
Purpose:
    Send pending records from Snowflake into Dynamics 365 Dataverse
    using either POST (create) or PATCH (update).

    INPUT  = VW_D365_REQUESTS
    OUTPUT = Dynamics 365 + Audit Logs + XREF updates

Me:  this is the end pipeline that sends to Dynamaics
==============================================================================


    +------------------------------------------------------+
    | LKP_GetRequests                                      |
    |------------------------------------------------------|
    | SELECT * FROM VW_D365_REQUESTS                       |
    | WHERE PipelineId                                     |
    |   AND SourceInstance                                 |
    |   AND EntityId                                       |
    +----------------------+-------------------------------+
                           |
                           |
                           v

    +------------------------------------------------------+
    | FE_ApiRequests (ForEach)                             |
    |------------------------------------------------------|
    | Parallel execution                                   |
    | batchCount = 5                                       |
    +----------------------+-------------------------------+
                           |
                           |
                           v

                   +--------------------+
                   | IF_PostOrPatch     |
                   +---------+----------+
                             |
          +------------------+------------------+
          |                                     |
          | POST                                | PATCH
          | New record                          | Existing record
          v                                     v

==============================================================================
LOGGING
==============================================================================

ALL RESULTS GO HERE:

    AUDIT_DB.MONITORING.SP_D365_LOG_RESPONSE

Records:

    Golden Record ID
    Entity
    Payload MD5
    HTTP Status
    Error Type
    Error Message
    Pipeline Run ID

Examples:

    SUCCESS (201)
    SUCCESS (204)

    HTTP_400
    HTTP_404
    HTTP_429
    TIMEOUT
    WEB_ACTIVITY_FAILED

    XREF_CAPTURE_FAILED


==============================================================================
XREF CAPTURE
==============================================================================

Example:

Snowflake Customer
    GR_1001

POST creates record in D365

D365 returns:

    CONTACTID =
    5B6E8A11-C12D-4D29-A123-XXXXXXXX

Stored by:

    SP_XREF_CAPTURE_D365_ID

Result:

    GR_1001
       |
       +-------> D365 CONTACTID

Future runs will use PATCH instead of POST.

This prevents duplicate customers.
