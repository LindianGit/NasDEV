High-level narrative

This ADF pipeline is a metadata-driven Dynamics 365 (Dataverse) extraction framework.

It reads a list of entities from a Snowflake metadata table and, for each enabled entity:

Validates pipeline parameters.
Retrieves configuration and current watermark values.
Skips entities that have failed too many times (circuit breaker).
Marks the entity as RUNNING.
Extracts data from Dynamics 365 via REST API.
Writes the data as compressed JSON (.json.gz) into Azure Blob Storage.
If it is a DELTA load, advances the watermark to the latest value found in Dataverse.
If it is a FULL load, leaves the watermark unchanged.
Records success or failure in Snowflake.
On failure, rolls the watermark back and increments the failure counter.

In short:

Snowflake metadata controls what to extract, ADF pulls data from Dynamics 365, stores it in Blob Storage, and maintains load state and watermarks in Snowflake.

Key Design Strengths
✅ Metadata Driven

Adding a new D365 entity usually requires:

Insert row into PIPELINE_METADATA


No pipeline change required.

✅ Incremental Loads

Uses:

$filter=<delta_column> gt <watermark>


Example:

modifiedon gt 2026-11-07T00:00:00Z


Only changed records are extracted.

✅ Circuit Breaker

After repeated failures (default 5):

CONSECUTIVE_FAILURES >= 5


Entity is skipped automatically.

Prevents one broken entity from constantly failing every run.

✅ Watermark Recovery

Before starting:

PREVIOUS_WATERMARK = WATERMARK_VALUE


If extraction fails:

WATERMARK_VALUE = PREVIOUS_WATERMARK


This prevents data loss.

✅ Parallelism
Pipeline concurrency = 1
ForEach batchCount = 8

---  Note this is good because at a later date Snowflake can extract from the Blob. 

Meaning:

Only one pipeline execution can run at a time.
Inside that execution, up to 8 entities can be extracted concurrently.
One-line summary for documentation

PL_D365_ExtractToBlob is a metadata-driven Azure Data Factory pipeline that incrementally or fully extracts Dynamics 365 (Dataverse) entities via REST APIs into Azure Blob Storage as compressed JSON files, while managing execution state, watermarks, retries, and circuit-breaker logic in Snowflake.
