Executive Summary
This assessment reviews the current Snowflake, MDM and ADF implementation supporting the migration to Dynamics 365. Existing code and design provide a starting point for Contacts and Accounts: the MDM task chain runs daily, and Dynamics payload views and related processing are present. The outbound connection to Dynamics, cross-reference handling and production readiness still need to be verified.
For Contacts and Accounts, the estimated core effort is 13–27 person-days, covering mapping review, connection testing, test loads and production cutover. If these tests are positive, the estimate drops dramatically. Conditional work—such as XREF validation, Dynamics-to-Snowflake ingestion and a HubSpot refresh—could add 9–21 person-days. These figures are indicative and depend on confirming scope, environment readiness and which components are already working.
Additional record types, including gifts, events and memberships, are not included in the Contacts and Accounts estimate and will require separate assessment. The current broader estimate is provisional and should be reconciled against the agreed object list before being used as a delivery commitment.
The recommended next step is to verify the live Snowflake and ADF configuration, confirm the Dynamics test environment and integration responsibilities, and close the mapping gaps. Then prove one object end to end—including ID capture and reconciliation—before extending the agreed pattern to other entities.

        AND START_TIME > DATEADD(hour, -30, CURRENT_TIMESTAMP())
      QUALIFY ROW_NUMBER() OVER (PARTITION BY TBL ORDER BY START_TIME DESC) = 1
    ) tr
    LEFT JOIN AUDIT_DB.CONFIG.PIPELINE_WATERMARK w
      ON w.PIPELINE_ID = 'RAISERS_EDGE'
     AND UPPER('STG_' || w.ENTITY_ID) = tr.TBL
    WHERE COALESCE(w.LAST_RUN_ROWS, 0) <= 5000000;
  tbl STRING;
  qid STRING;
BEGIN
  FOR r IN c1 DO
    tbl := r.TBL;
    qid := r.QUERY_ID;
    BEGIN
      EXECUTE IMMEDIATE
        'INSERT INTO TMP_STG_COL_POP ' ||
        'SELECT ''' || tbl || ''', ''' || qid || ''', f.key, COUNT(*), ' ||
        'COUNT_IF(NULLIF(f.value::STRING, '''') IS NOT NULL) ' ||
        'FROM (SELECT OBJECT_CONSTRUCT_KEEP_NULL(*) AS OBJ ' ||
        'FROM RAW.RAISERS_EDGE.' || tbl || ' BEFORE (STATEMENT => ''' || qid || ''')) t, ' ||
        'LATERAL FLATTEN(INPUT => t.OBJ) f GROUP BY f.key';
    EXCEPTION
      WHEN OTHER THEN
        INSERT INTO TMP_STG_COL_POP_ERR VALUES (:tbl, :qid, :SQLERRM);
    END;
  END FOR;
  RETURN 'done';
END;  $$;
